# Chrome Web Store Listing Details

## Extension Name
SerpScoop - Email Extractor

## Short Description (132 chars max)
Extract emails from Google search results and landing pages. Fast background processing with domain filtering.

## Detailed Description

🔍 **SerpScoop** is a powerful email extraction tool for Google Search results.

### How It Works
1. Search Google for your target audience
2. Click "Run" in the extension popup
3. SerpScoop extracts emails from search descriptions
4. Links are queued for background processing
5. Extension auto-clicks "Next" - you click "Run" again
6. Emails from landing pages appear as they're found

### Key Features

✅ **Fast SERP Extraction** - Instantly captures emails visible in search results
✅ **Background Processing** - Deep link scraping happens while you paginate
✅ **Anti-Detection** - Random 2-5 second delays between requests
✅ **Domain Filtering** - Filter results by email domain (e.g., @gmail.com)
✅ **Export Options** - Copy to clipboard or download as CSV
✅ **100% Local** - All data stays on your device, nothing sent to servers

### Perfect For
- Lead generation
- Sales prospecting
- Market research
- Recruiter outreach
- Business development

### Privacy First
All data is stored locally using Chrome's storage API. No external servers, no tracking, no analytics.

### Permissions
- activeTab: Read current search page
- storage: Save emails locally
- tabs: Detect search pages
- host_permissions: Fetch external pages for email extraction
